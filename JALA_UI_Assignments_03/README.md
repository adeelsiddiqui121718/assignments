# UI Assignments

This folder contains a clean GitHub-ready structure for the HTML, CSS, JavaScript, and AngularJS assignment examples.

## Structure

- `html/`
  - `basics.html` — HTML5 basics and page navigation examples
  - `input-attributes.html` — HTML5 form inputs and target attribute examples
  - `semantic-elements.html` — HTML5 semantic tag examples

- `css/`
  - `basics.css` — CSS comments, backgrounds, borders, dimensions, font styles
  - `page-adjustments.css` — table hover, visibility/display, scroll behavior, spacing
  - `effects.css` — box shadow, animation, positioning, overflow
  - `compatibility.css` — table layout, list style, grid layout

- `javascript/`
  - `basics.js` — JS comments, array sort, loops, object access, hoisting, strict mode
  - `access-properties.js` — `this`, call/apply, counter, getter/setter
  - `events.js` — event listener, validation helper, cookies

- `angularjs/`
  - `basics.html` — AngularJS module, controller, expressions, ng-model, rootScope
  - `filters.html` — built-in and custom filters, $timeout example
  - `json.html` — JSON table display, ng-repeat, ng-options
  - `events.html` — ng-click, ng-show, ng-disabled, ng-mousemove
  - `elements-validations.html` — form validation, custom directive, animations

## Usage

Open any HTML file in the browser to preview the example.
For AngularJS files, an internet connection is required to load the AngularJS CDN.
