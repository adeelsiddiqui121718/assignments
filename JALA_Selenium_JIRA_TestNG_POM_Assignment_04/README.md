# Selenium, JIRA, TestNG and POM Assignment

## Assignment Overview
This folder is for the Magnus application Selenium testing assignment. It covers:
- writing test scenarios
- writing test cases
- automating the same cases using Selenium
- logging 5 defects in JIRA
- understanding the role of TestNG and the Page Object Model (POM)

## What to do here
1. Keep your documentation in VS Code for:
   - test scenarios
   - test cases
   - defect descriptions
2. Use Selenium to automate the key test cases.
3. Log 5 defects in JIRA using the details you find in the application.
4. Learn TestNG for running test suites and assertions.
5. Learn the Page Object Model (POM) to organize Selenium page logic.

## Recommended Folder Structure
- `scenarios/` — test scenario documents
- `test-cases/` — test case documents
- `defects/` — JIRA-ready defect logs
- `automation/` — Selenium scripts and POM classes

## Sample Scenarios to Cover
