# Assignments Repository

This repository contains training assignments for Java, SQL, UI, Selenium, RESTful services, and software testing.

## Folder Overview

- `JALA_JAVA_Assignments_01/` — Java fundamentals and practice programs covering basic syntax, operators, loops, arrays, static members, strings, inheritance, access modifiers, abstract classes, interfaces, constructors, exception handling, file I/O, and collections.
- `JALA_Magnus-Testing_Assignment_06/` — Test scenarios, test cases, defect logs, and Selenium automation for the Magnus application.
- `JALA_RESTful_Web_Services_Assignment_05/` — REST API concepts and API testing learning resources.
- `JALA_Selenium_JIRA_TestNG_POM_Assignment_04/` — Selenium automation, JIRA defect logging, TestNG, and POM guidance.
- `JALA_SQL_Assignments-02/` — SQL assignments for DDL, SELECT queries, filtering, sorting, operators, unions, constraints, and aggregate functions.
- `JALA_UI_Assignments_03/` — Web UI practice with HTML, CSS, JavaScript, AngularJS, and page examples.

## How to Review

1. Open the root README first to understand the assignment map.
2. Review each assignment folder and its README file for details.
3. Verify code and documentation in the folder that matches the assignment topic.
4. Use `SETUP_GUIDE.md` to follow environment setup and run instructions.

## Notes

- `QUICK_REFERENCE.md` contains quick navigation and summary notes.
- `SETUP_GUIDE.md` explains how to run Java code, SQL files, UI pages, and Selenium automation.
- `JALA_JAVA_Assignments_01/README.md` provides an organized overview of the Java practice files.
