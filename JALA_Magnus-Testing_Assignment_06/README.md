## Folder Structure

- `test-cases/` — Detailed manual test cases

## Notes
1. The Selenium script uses placeholder selectors for the login fields. Update them after confirming the actual page element IDs or names.
2. Run the automation scripts using Python 3 and the Selenium WebDriver for Chrome.
3. Use the Markdown files for manual test execution and JIRA defect creation.
